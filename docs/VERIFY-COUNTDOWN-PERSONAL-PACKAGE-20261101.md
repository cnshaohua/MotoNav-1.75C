# 读秒版个人包名修订

本次保留 8.3.26-single.32-fresh.1 的五栏界面和导航策略，修改完整构建时的安装身份；普通版、iOS、圆屏固件不在此修改范围。

新工程首次生成并保存个人包名；旧工程保留既有包名和签名。后续构建沿用 `personal.properties` 与 `.local/debug.keystore`。成品权限、读秒同步、兼容组件的数据路径、原生文件哈希与成品包名一致，JNI 类名保持原名。

验证包括：15 项身份/迁移/权限/原生路径/证书输出回归，5 项依赖下载回归，原有路线与读秒策略回归；Windows 完整构建和成品 APK 包名、签名、对齐、资源引用与类重复检查。检查成品原生文件与编译时哈希一致、读秒广播权限与清单一致，以及重复构建使用相同身份和签名。公共源码 ZIP 排除个人身份文件、签名、第三方 APK、构建缓存与个人 Key。

可指定最多 21 个 ASCII 字符的包名，超长明确拒绝；这个限制来自兼容组件的原生数据路径，不能只改 Gradle 后忽略最终合包。直接 Gradle 产物仍只是中间包，不能替代完整构建。
